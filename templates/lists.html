Computer Components

Explore the essential parts of a computer system, from input devices to storage components and processing units.

01 Input Devices

Input Device

Devices used to enter data and instructions into a computer.

  1. Direct Input
    • Scanner
  2. Indirect Input
    • Keyboard
    • Mouse
02 Output Devices

Output Device

Hardware components that display or produce processed information.

  1. Monitor
    • CRT Monitor
    • LCD Monitor
  2. Speaker
03 Processing Unit

Processing Device

The brain of the computer responsible for executing instructions.

  1. ALU (Arithmetic Logic Unit)
    • Arithmetic Unit
    • Logic Unit
  2. CU (Control Unit)
04 Storage Devices

Storage Device

Components used to save and retrieve computer data.

  1. Primary Storage
    • RAM
      1. DRAM
      2. SRAM
  2. Secondary Storage
    • Hard Disk Drive (HDD)
    • Solid State Drive (SSD)
    • Flash Storage
